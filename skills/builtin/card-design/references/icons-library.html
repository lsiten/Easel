card-design · 线性图标库（替代 emoji）

规则（anti-ai-slop.md P0）：禁 emoji 当图标。需要图标时，从本库取一个 Lucide 线性图标（stroke 1.5、24 网格、currentColor、无 fill），或纯排版—— 绝不用 emoji。每处最多 1 个图标，颜色只用 accent / 灰 / 墨。

用法：把下方 <svg>…</svg> 整段复制进卡片 HTML， width/height 按需要改（24/32/48），color 用 CSS 控制 （color:var(--accent) 即描边色）；描边粗细 stroke-width="1.5" 固定。

双栏 / 对比卡 · 配色与图标位（对齐 OpenMontage 做法）

「禾城」这类双栏卡的问题不是缺图标，是用 emoji 当图标 + flex 居中。 正解：等宽双栏 + 一条 2px 分隔线 + 每栏顶部一条 48×4 色条（色=立场色，不渐变）+ 图标用上面 SVG。

没有对应图标就纯排版（色条 / 序号 / 发丝线），宁可不用图标也不上 emoji。 勾用 check 图标，或用 CSS 描边画的勾（::after 里旋转 border 画勾 / 内联 check 的 SVG 描边），绝不用彩色对勾符号。

渲染前必跑（确定性门禁）

卡片 HTML 写好后、出图前，跑一遍「禁 emoji」门禁；检出 emoji 即 FAIL，换图标重渲。 已内置进 render_card.py --fail-on-emoji（渲染前自动跑）；也可单独跑：

python skills/shared/scripts/check_no_emoji.py --html outputs/主题名/card.html

同时跑密度门禁 card_audit.py（死空白/填满）。两个都 PASS 才交付。
