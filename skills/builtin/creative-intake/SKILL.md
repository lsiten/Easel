# 创作意图采集（Creative Intake）

> 提取已有意图，仅澄清影响执行的缺口。用 `intake_brief` 传递用户要求与明确标注的假设。
> 视频默认交给 OpenFilm，用户选择专用流程时保留该选择。
>
> 思路沉淀自 OpenMontage `method/skills/meta/creative-intake.md`，适配 Easel 制作层。

## 什么时候用

**用**：用户给主题/需求但**模糊**（"帮我做个视频""做个关于 X 的""你看着办"），且缺失的信息会实质影响制作方向。用户授权自行决定时采用合理选择并简要说明。
**不用**（直接路由）：
- 用户给**参考视频**说"做个类似的" → 走 [video-reference-analyst](../video-reference-analyst/SKILL.md)（参考本身就是调性/结构的答案，别问"想做成什么样"）
- 用户给**完整 brief**（多段说明，已含目的/受众/调性/平台）→ 直接路由，仅澄清阻碍执行的缺口
- 用户只写脚本/只配音/只取音乐 → 直接走对应零件 SKILL

## 可用的意图线索

1. **目的**：这条是给谁看、为了什么？（科普 / 卖货 / 激励 / 记录 / 娱乐）
2. **受众**：谁会看？（年龄 / 专业度 / 场景——"我团队内部" vs "抖音公域"）
3. **平台**：发在哪？（抖音 / 小红书 / B站 / 内部 / 网页 / 演示）
4. **调性**：要什么**感觉**？（认真 / 活泼 / 电影感 / 原生 / 温暖 / 有冲击力）
5. **参考**：有没有喜欢的视频 / 想"像 XX 那样"？
6. **期望**：看完后希望观众**做什么 / 感受什么**？
7. **约束**：预算上限？时长？必须出现的内容？

## 怎么问

- **不要一次抛 7 题**。先问目的和受众，让对话自然流动，边聊边补。
- **用户已答的别再问**：用户说"我要一条小红书上的电影感品牌片"——你已拿到目的（激励/卖货）、平台（小红书）、调性（电影感），只问缺的。
- **别问用户已答的题**，别把对话做成填表。

## 处理模糊 brief（"帮我做个关于 X 的视频"）

1. 先**接住主题**（表明听懂了）；
2. 先问**最关键的 1 个缺口**（通常是目的或受众）；
3. 据回答问下一个缺口；
4. 到**够开工**就停——不需要完美答案，下游会补细节。

## 处理完整 brief

1. 用 1–2 句**复述**你的理解；
2. 复用已确定的平台、画幅与约束，直接开始制作。
3. 仅对阻碍执行或影响已授权预算的歧义提出必要问题。

## 产出 intake_brief（非正式 schema，供下游用）

```
- 目的 / 受众 / 平台 / 调性 / 期望 / 约束（标出"用户说的" vs "你推断的"）
- 用户原话里能反映意图的引用
- 提到的参考视频 / 图片
- 必须守住的约束（预算 / 时长 / 必含内容）
```

`intake_brief` 作为**上下文**交给下游引擎（不强制落盘），作用是**防止下游发明用户从没表达的意图**。

## 与下游的衔接

- 做视频默认交给 [video-openfilm](../video-openfilm/SKILL.md)，包括实拍混剪、静图动效、口播和动态图形。默认交付可编辑项目与 Studio 预览，用户要求导出或发布时渲染 MP4。
- `stock-footage`、`ai-image-gen`、`ai-video-gen`、配音和音乐 skills 按项目需要供料，由 OpenFilm 编排。
- 用户明确选择一键口播流水线、已有整片剪辑或多角色短剧等专用流程时，保留其 `auto-short-video`、`video-production`、`short-drama` 等选择。
- 小红书图文交给 [xhs-note-creator](../xhs-note-creator/SKILL.md)，仅要脚本、配音或素材时直接使用对应零件 skill。
- 复用用户已给的画幅、参考和平台约束。信息足以开工或用户授权自行决定时，说明采用的画幅后继续制作。
- 有 Profile 时使用 `style.md`、`platforms.md`、`preferences.md` 补充已有约束，用户当前要求优先。

## 不要做

- 不要抛编号问卷——是对话不是填表。
- 不要问用户已答的题。
- 不要无故拖延制作——brief 够清就往下走。
- 不要替用户没提的问题编答案——标"未指定"，让下游处理歧义。
- 不要假设用户想要 explainer——有人要电影感 / 动画 / 实拍，听信号。
